SPF Brightness Hotkeys 1.0.1
Independent SPF plugin; Console Command Hotkeys is not required.
Brighter, Dimmer, Reset brightness and Open brightness settings are bindable in SPF.
Open the Brightness settings window in SPF to configure step, reset and starting value.
Only saved ATS config or tracked plugin values are available, not live cvar readback.
Separate console/graphics changes require reloading or applying a known value.
Initial activation reads saved config without changing brightness.
Package includes Console Command Hotkeys 1.0.3-split, which removes duplicate brightness controls.
Preserve all config folders. Existing settings and brightness bindings have been migrated locally.
No default keys are assigned to the new plugin. Custom console commands and seat controls remain unchanged.
Based on the brightness implementation from the modified Track & Truck Devs Console Command Hotkeys plugin; original license retained.
